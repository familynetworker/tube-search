# AI Creators & Builders Tube Search

Faceless YouTube channel intelligence for Windows: newly launched long-form, Sleep and Shorts channels, with views, estimated revenue, recent videos and niche ideas.

## Download

**[Download the latest TubeSearch-Setup.exe](https://github.com/familynetworker/tube-search/releases/latest/download/TubeSearch-Setup.exe)**

1. Run `TubeSearch-Setup.exe`.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. Open **Tube Search** from the Start menu.

The app updates itself: when new channel data is published, you'll see a notice inside the app.

Requires Windows 10 or 11.

Revenue, RPM and monetization figures are estimates.
